### Dans cette version

- **Les crises de fin s'annoncent comme la fin du monde.** Les cinq annonces sont réécrites : les tombes s'ouvrent, le givre noircit les récoltes, les cités se soulèvent contre vous. Sous le titre : « La fin des temps commence ».
- **Un sort qui ne peut pas viser une unité dit pourquoi.** La Toile lancée sur des Spectres répondait « Sort annulé », puis transformait votre clic en ordre d'attaque et se plaignait que l'unité vole. La Toile prend bien les volants ; les Spectres sont incorporels, et la toile passe à travers. C'est ce que le jeu dit maintenant, et le sort reste prêt pour une autre cible. Tous les sorts de combat donnent ainsi leur vraie raison : immunité, mauvais camp, effet déjà en place, etc. La description de la Toile mentionne les unités incorporelles.
