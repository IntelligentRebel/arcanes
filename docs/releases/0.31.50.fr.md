### Dans cette version

- Une copie hors ligne à laquelle il manque un fichier le dit au lancement, et le nomme : une image absente ou d'une version antérieure, ou un fichier de langue qui ne correspond pas. Une mise à jour a sans doute été sautée ; le jeu entier remet tout en ordre.
- Portraits animés : quand votre système demande moins d'animations (sous Windows, « Effets d'animation » coupés), ils restent figés, et le menu le dit au lieu de les prétendre activés. Un clic les active quand même.
