### Dans cette version

- La fin d'une partie montre désormais le sorcier concerné. Une victoire par conquête montre votre sorcier sur les remparts de sa capitale, au-dessus d'un défilé sans fin de tous les peuples ; le Sort de Maîtrise le montre au sommet d'une tour, une colonne de lumière montant vers les cieux. Une illustration de chaque pour les 14 sorciers.
- Si un rival accomplit le Sort de Maîtrise, vous voyez son triomphe ; si vous perdez votre dernière cité, vous voyez la chute de votre propre sorcier.
- L'illustration est plus haute sur l'écran de fin : le sorcier n'y est plus rogné.
