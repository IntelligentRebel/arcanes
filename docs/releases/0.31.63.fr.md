### Dans cette version

- **La coalition et le Démon légendaire ne visent plus le sorcier de l'autre plan.** Les sorciers jaugent le meneur sur votre plan : si vous y prenez trop d'avance, c'est vous qu'ils visent, même quand le boss d'en face est plus fort. Les sorciers d'en face n'entrent pas dans le pacte.
