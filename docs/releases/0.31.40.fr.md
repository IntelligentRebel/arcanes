### Dans cette version

- **Dossier de sauvegarde.** La copie de votre partie, écrite tous les quelques tours, peut désormais aller directement dans un dossier de votre choix, sans fenêtre de téléchargement à chaque fois : Menu ▸ Dossier de sauvegarde. Le navigateur demande une fois par session de confirmer l'accès, et c'est tout. Cela repose sur l'API File System Access : Chrome et Edge la connaissent, Firefox et Safari non, et dans ce cas le menu le dit et les copies continuent d'aller dans vos téléchargements.
