**Play in your browser:** https://intelligentrebel.github.io/arcanes/

### In this version

- **Save folder.** The backup copy of your game, written every few turns, can now go straight into a folder of your choosing, without a download popup every time: Menu ▸ Save folder. The browser asks once per session to confirm access, and that's it. This uses the File System Access API, so it works in Chrome and Edge; in Firefox and Safari the menu says so and the copies keep going to your downloads as before.
